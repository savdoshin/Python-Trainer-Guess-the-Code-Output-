# 🐍 Python Trainer: Guess the Code Output

Интерактивный тренажёр для студентов, изучающих Python. 

## Как играть
1. Смотрите на фрагмент кода.
2. Выбираете, что выведет программа.
3. Получаете мгновенный фидбек с пояснением.

## Темы
- Списки (append, pop, copy, изменение по индексу)
- Словари (get, keys, pop, вложенные структуры)
- Хитрые случаи (ссылки vs копии)

## Технологии
- Чистый HTML + CSS + JavaScript
- Без внешних зависимостей
- Адаптивная вёрстка
